\# Solar PV Plant Performance Monitoring \& Loss Diagnostics



A data-driven platform for monitoring the operational performance of solar photovoltaic (PV) plants and diagnosing generation losses.



\## Objective



The project analyzes plant operational data to:



\- Validate SCADA generation data

\- Compare actual generation with expected generation

\- Calculate key plant performance indicators

\- Identify potential sources of generation losses

\- Quantify the financial impact of underperformance

\- Present results through an interactive dashboard



\## Key KPIs



\- Performance Ratio (PR)

\- Capacity Factor

\- Plant Availability

\- Generation

\- Generation Loss

\- Revenue Loss



\## Loss Categories



The system will attempt to identify losses associated with:



\- Inverter downtime

\- Tracker downtime

\- Grid curtailment

\- Equipment derating

\- Soiling

\- Metering discrepancies
